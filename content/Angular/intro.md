# Introduction to Angular

## What is it

Angular is a single page web application framework that is maintained by Google. Angular uses a component based architecture where each component encapsulates its html, css, and javascript. 

## Why to use it

Angular contains tools, libraries, APIs, and build tools that allow you to build robust and scalable applications for web, desktop, and mobile. This will allow you to get started developing features early rather than spending time setting up the application. 

Angular has strong community support and is a good choice for enterprise level applications that need to be scalable and maintainable.

## Why not to use it

Angular is more geared towards enterprise level applications, has a steep learning curve, and while it has performance benefits it does need to be configured properly. Smaller applications might be better suided for lighter frameworks like React or Vue.
