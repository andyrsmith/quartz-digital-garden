# Starting a New Angular Project

To start a new Angular project run

```
ng new <name-of-project>
```
or

```
ng n <name-of-project>
```

This will launch an interactive menu that will ask you a series of questions about how you want to set up your application. Once you finish with all of the questions it will create the directories and neccessary files and run npm install.

Once the install is complete you are ready to start the application.
