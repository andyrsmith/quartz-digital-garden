# Install Angular

A prerequisite for installing Angular is to have node installed on your machine.  

Check with the Angular compatibility to see which version of node you need.

https://angular.dev/reference/versions

Once node is installed then run npm install with the -g flag.  Dash g will install it in your global module so that you will be able to run the angular commands from any directory location in your terminal

```
npm install -g @angular/cli
```

or 

```
npm install -g @angular/cli@20
```

This will install latest release of Angular v20.  Replace 20 with whatever version you need. 

To check the version of Angular that is install run the following command in your terminal.

```
ng version
```
